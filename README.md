# Yaari Dosti

A full dating website starter with auth, profiles, matching, chat, and Stripe subscriptions.

## Stack
- React frontend
- Node/Express backend
- MongoDB
- Socket.IO
- Stripe integration
- Docker support

## Run locally
1. Install Docker Desktop
2. In repo root: docker-compose up --build
3. Frontend: http://localhost:3000
4. Backend: http://localhost:4000

## Env files
- backend/.env.example -> backend/.env
- frontend/.env.example -> frontend/.env

## Important
Set real production secrets before deploying.
